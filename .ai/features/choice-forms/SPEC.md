# Spec: sharing and posting forms

The full spec, its checks and the council's decisions: [less-choice SPEC, Part 5](../less-choice/SPEC.md). The approved
scope and the small calls: [CHARTER.md](CHARTER.md). How it works: [NOTES.md](NOTES.md). Proof: [reports/VERIFY.md](reports/VERIFY.md).

## What it does now
- Library, share: a title, one box ("Paste it, link it or attach a file"), the guessed Kind with "Change", then Share.
  Pitch, Role, install steps, a link and who can see it ("Whole portfolio") sit under More options. The secret scan
  reads every pasted text, not only files.
- Our jobs: "Add a job" first (title, location, an optional link or email); with no link, Apply on the members' board
  messages the founder. "Already on Greenhouse, Lever…? Paste your careers link" second, with no tool list. One card
  per company.
- A hiring request made from a job: the job's first one each week uses no weekly ask, and the button says so.
