# Personas, jobs and journeys (made up)

All people below are invented. None is a demo member of the app.

## Jobs each role hires the app for

**Founder**
- F1 Get quick help from a peer who has done this.
- F2 Drop into a live room (talk now, or hear others who are talking).
- F3 Get a warm intro (a customer, an investor, a hire).
- F4 Help another founder (answer an ask, make an intro) without it eating my day.
- F5 Hire and save money (jobs, candidates, perks, shared AI tools).

**Portfolio manager / platform lead**
- M1 Get founders to show up (live rooms, replies, logins).
- M2 Announce something to all or some founders.
- M3 See the asks and who needs help, and nudge the right person.
- M4 Bring founders in (invite, import, first-week setup).
- M5 Show the partners it works (the report).

**Fund partner**
- P1 See which companies need help, and where I can step in.
- P2 See whether the community is worth the fund's time (one number, one page).
- P3 Make an intro in under a minute.

**Mentor**
- R1 Offer office hours (host a room, share a booking link).
- R2 Answer asks in my area only.
- R3 Control when the app interrupts me.

## Journeys through today's screens (screens in order)

Member screens: screenshot `member-<screen>-phone.png` / `-desktop.png`, text `member-<screen>.txt`.
Admin screens: `admin-<screen>-…`.

- F1 quick help: today → asks → ask (post form) → asks_[id] (one ask) → inbox → inbox_[id]
- F2 live room: today (find Rooms; look at the phone tab bar) → rooms → rooms_[id] / room-joined → me_alerts (get told when a room opens)
- F3 intro: search → directory → people_[id] → intros_new (ask form) → intros → intros_[id]
- F4 help others: today ("You could help with these") → asks_[id] → intros (the one waiting for your yes) → intros_[id]
- F5 hire and save: jobs → perks → library → library_leaderboard → directory
- Profile and settings (every member, first week): me → me_email → me_alerts → me_data → me_network
- M1 show up: admin (console home) → admin_rooms → member rooms → admin_features → admin_announcements
- M2 announce: admin → admin_announcements → admin_digest (weekly email)
- M3 asks: admin → admin_asks → admin_reports → admin_intros
- M4 bring founders in: admin_invites → admin_import → admin_members → admin_members_[id] → admin_setup → admin_start → admin_settings
- M5 report: admin_report → admin_calls → admin_intros
- P1/P2/P3 partner: admin → admin_report → admin_asks → admin_members → member today → directory → people_[id] → intros_new
- R1–R3 mentor: today → rooms → me (booking link, privacy) → asks → asks_[id] → me_alerts → inbox
