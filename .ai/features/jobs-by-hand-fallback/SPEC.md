# Our jobs: when a link has no job board

On "Our jobs" (My profile › Our jobs), a careers link with no job board in it shows Commonhall's message and an
"Add the jobs by hand instead" button. The button starts that company with jobs added by hand, and the "Add a job by
hand" form opens under it. Asking again for the same company by hand returns the
one already there ("<company> is already here. Add its jobs below."), so a second click never adds a copy.
